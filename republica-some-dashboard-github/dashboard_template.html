Vis som datatabel

Opslag

Reach — antal unikke personer der har set opslaget. LinkedIn: uniqueImpressionsCount · Facebook: post_impressions_unique · Instagram: reach.
Engagement — reaktioner + kommentarer + delinger (+ gemte på Instagram). Klik tælles separat.
Engagement rate — engagement delt med reach. Beregnes på reach, ikke følgere, så tal kan sammenlignes på tværs af platforme.
Klik / CTR — link- og indholdsklik delt med impressions. Instagram giver ikke klik pr. opslag, og feltet vises som “–” frem for 0.
Video — visninger på 3+ sekunder, gennemsnitlig visningstid og gennemførelsesgrad (gns. visningstid / videolængde).
Nye følgere — følgere tilskrevet opslaget. Findes kun på Instagram og LinkedIn; Facebook rapporterer det ikke pr. opslag.
